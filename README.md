# Parlez-Vous-QSO?! – Weboberfläche / Web interface

**Deutsch** | [English](#english)

Dieser Fork ergänzt das Projekt [**Parlez-Vous-QSO?!**](https://github.com/MichaelRenner/Parlez-Vous-QSO) um eine durchsuchbare Weboberfläche mit Sprachausgabe und Rufzeichen-Erkennung.

**→ Zur Weboberfläche: https://fotomensch.github.io/Parlez-Vous-QSO-web/web/**

Alle Inhalte – Sprachführer, Lautschrift, PDFs, Hinweise zur Mitarbeit – stammen aus dem Original-Projekt:
**https://github.com/MichaelRenner/Parlez-Vous-QSO**

Korrekturen und Ergänzungen an den Sprachführern bitte dort einreichen. Technische Details zur Weboberfläche stehen in [`web/README.md`](web/README.md).

## English

This fork adds a searchable web interface with speech output and call sign lookup to the [**Parlez-Vous-QSO?!**](https://github.com/MichaelRenner/Parlez-Vous-QSO) project.

**→ Open the web interface: https://fotomensch.github.io/Parlez-Vous-QSO-web/web/**

All content – phrase books, IPA transcriptions, PDFs, contribution guidelines – comes from the original project:
**https://github.com/MichaelRenner/Parlez-Vous-QSO**

Please submit corrections and additions to the phrase books there. Technical details about the web interface are in [`web/README.md`](web/README.md).

### Thanks

**Special thanks to Steve, M0ECS**, who had the idea for “Parlez Vous QSO” and created the original phrase books, **and to Michael Renner**, who continues the project with Steve's agreement and converted it to LaTeX and PDF, added IPA transcriptions and further languages. This web interface would not exist without their work.

Thanks also to everyone credited as authors and translators in the individual language versions.

73 de Jörg, DB6WZ
